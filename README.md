# MathsPS CRM & ERP System

Custom CRM and Analytics platform for lead management, student payments, automated delivery tracking, and performance reporting.

## Overview
- **CRM Web & Virtual HQ:** Next.js 16 / React 19 / Supabase application.
- **Lead Tracking:** Complete multi-grade lead lifecycle and conversion tracking.
- **Student & Payment Management:** Household, enrollment, and payment reconciliation.
- **Reporting & Automations:** Executive daily/weekly/monthly email reports and matrix summaries.

## System Architecture
- Built for **Prabuddha Sampath**
- Fully automated CRM & payment management
